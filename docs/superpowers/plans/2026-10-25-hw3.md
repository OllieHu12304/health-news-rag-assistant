# 健康新聞 RAG Implementation Plan

> 執行方式：使用者已指示開始實作，由目前工作階段直接完成。

**Goal:** 在 nlp_hw3 建立可重現、附來源的地端健康新聞多輪問答。
**Architecture:** SQLite 保存爬取文章與地端摘要；E5-small 正規化摘要向量與 ID 對照以 NumPy 保存；MLX 生成回答，Streamlit 保存每個 session 的多輪歷史。
**Tech Stack:** Python 3.13、uv、MLX-LM、Transformers/PyTorch（CPU embedding）、SQLite、Streamlit。
**Spec:** DESIGN.md，使用者於 2026-10-25 授權開始實作。

## Global Constraints
- 僅修改 nlp_hw3，使用 Qwen2.5-3B-Instruct-4bit 原始模型，不載入作業二 adapter。
- 至少六個資料欄位、指定網站分類、地端摘要、摘要向量、多輪問答、checkbox、兩題與整理、每輪來源。
- 發布時間 published_at 為引用的文章新增時間；crawled_at 為爬取時間。
- embedding 使用 intfloat/multilingual-e5-small（512 tokens），passage:/query: 前綴與遮罩 mean pooling；記錄實際 revision。

## Review Focus
- 網頁缺全文或日期不能悄悄以導覽文字／目前時間代替。
- 文章變更清除舊摘要；索引失配應要求重建。
- 關閉檢索仍保留實際前文來源，首次無來源不編造。
- 重點整理只使用對話與既有來源；不新增不相干新聞。
- 無資料、無摘要、無索引、模型缺失皆提供可操作訊息。
